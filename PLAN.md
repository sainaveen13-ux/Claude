# Turning $100 of cloud credits into money

## What the $100 actually is
- It's **compute for Claude Code cloud sessions** (like this one). It is not cash, it can't be withdrawn, and it can't pay for anything outside these sessions.
- It **expires Nov 5, 2026**, so any credit still unused then is lost.
- So there's only one way to make money with it: use the sessions to **build things that earn money** (tools, content, code for paying clients, bounty fixes), and then use free hosting and your own accounts to sell or ship them.
- Free resources you already have: GitHub (you get free Pages hosting), VidIQ, Gmail, Drive, Indeed, and your YouTube channels (Alpha Glitch, Rupaya Files).
